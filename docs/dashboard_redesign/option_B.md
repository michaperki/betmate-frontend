🏠 New BetMate Home Dashboard — Overhaul Plan
1. Page Layout (Macro Structure)

Replace the current “stack of boxes” with a three-section layout:

A. Hero Header (Compact + Identity-Forward)

Left:
“Welcome back, <username>” + small avatar + balance

Right:
Quick Actions → “Deposit Tokens”, “View Active Matches”

Background: a subtle animated gradient or dark gloss bar

Keeps the user’s identity + core metrics visible without taking half the page.

2. Replace Balance History Chart With “Portfolio Snapshot”

The downward red chart looks depressing and also useless.

Create a 3-card horizontal stat row:

Balance (primary, bold)

Wagers placed

Win rate

Small sparkline chart under each card (success: green / activity: blue).

This gives clarity without a giant scary graph dominating the UI.

3. Featured Match → New “Live & Featured Matches” Module

Turn it into a carousel or two-tile row:

Tile Format

Player faces → vertical vs instead of horizontal

Match type badge (LIVE / HIGH STAKES) in neon pill

“Join Game” button below

Subtle board impression background

More compact, more premium, much less “giant empty box”.

4. Leaderboard → Shrink + Improve Visual Hierarchy

Make it a small, tight card with:

A crown icon

Top 3 only (with “See Full Leaderboard” button)

Better color logic:

#1 gold

#2 silver

#3 bronze

Right-aligned scores in muted gray instead of screaming red

This is currently visually noisy—tightening it increases professionalism.

5. Add a “Continue Playing” Strip

Right under the hero section:

Continue your match → zweidrei vs emadal
A narrow, tappable, high-contrast strip similar to Spotify’s “Continue Listening”.

Lets returning users reenter instantly.

6. Add a New “Insights” Module

Small row of digestible info, like:

Your best opening

Longest hot streak

Moves predicted correctly this week

Gives stickiness + personality without clutter.

7. Add a New “Upcoming Events” Section

Even if sparse at first, it makes the product feel alive.

8. Design Style Direction

Short + practical:

Rounded 12–16px corners everywhere for a modern sportsbook aesthetic

True neumorphism / glow elements for match tiles only

Reduce neon accents → use neon only for CTAs (Join, Bet, Resume)

Increase whitespace vertically by 20–24px

Use a consistent pixel grid (8px baseline)

Result: clean, airy, professional.
