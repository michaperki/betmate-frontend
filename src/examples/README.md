# Examples

This directory contains examples of components and patterns that are not currently used in the main application but are preserved for reference.

## ButtonDemo

The ButtonDemo component showcases all the available button variants, sizes, and states. It was previously included in the Dashboard component for development purposes but has been moved here to keep the production code clean.

To use the ButtonDemo, you would import and render it in your component:

```tsx
import ButtonDemo from 'examples/ButtonDemo';

// In your component's render method:
<ButtonDemo />
```
